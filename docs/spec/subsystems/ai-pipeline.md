# Subsystem: ai-pipeline (single-post COMBINED/JUDGE path + AI client)

> Traced from code. Confirmed defects live in the defect register `known-issues.md`, which is not part of the public copy; [KNOWN-LIMITS.md](../KNOWN-LIMITS.md) carries what a reader outside the project needs from it. Re-read against the code in the 2026-08-23 objective audit (spec-drift.md items 44 to 52).

## Purpose

Receives a single PostContent from the content-script queue, runs it through pre-LLM cost-zero filters (parent blocklist, slur, coded harm, sponsored, profanity, dehumanization, violence-narrating-video, harm-floor), then calls the AI provider through the licensed proxy (Deep Infra since 2026-09-21, Groq before). In Child and Teen: openai/gpt-oss-20b, the parent-frame judge, detection and rewrite in one call. In Adult (since 2026-09-03): openai/gpt-oss-120b asked JUDGE-V1's own question under a strict schema, fire at charged and severity 4, the rewrite a second call on the rewrite-only path (docs/research/accuracy-2026-09-03/RESULTS.md). Returns a PipelineResult action tag (pass/neutralize/collapse/hide/mark/cancelled) plus NeutralizedContent and AnalysisResult for the forensic chain. Includes a two-stage triage cascade (TRIAGE_STAGE1 → JUDGE_DETECT_NEUTRALIZE), a rewrite validator with shared final visible-output language safety, per-call telemetry, a module-private concurrency limiter for the proxy fetch, and a proxy-cap latch.

## Inputs

PostContent (text, id, platform, author, kind, is_sponsored, context) from the content-script processing queue (src/content/index.ts). Optional AbortSignal from the per-item queue controller. Settings (mode, locale, dailyCap, strictLanguage, outputLanguage) from chrome.storage. License (tier, secret) from src/storage/license.

## Outputs

PipelineResult to src/content/index.ts onProcessingResult router, which dispatches: action='neutralize' → DOM rewrite injector + FORENSIC_LOG; action='hide'/'collapse' → DOM hide + FORENSIC_LOG; action='mark' → severity dot only + FORENSIC_LOG; action='pass' → FORENSIC_LOG with verdict='pass' (post-llm-* reasons only); action='cancelled' → CANCEL_LOG; a genuine vendor / network failure on a paid tier → passWith('pre-llm-ai-call-failed') with `failureKind`, which onProcessingResult turns into a CANCEL_LOG with verdict 'cancelled-post-llm-failure' (cap exhaustion excluded).

## Invariants & contracts

- **A rewrite needs two judges to agree (JUDGE-V1-PAIR, 2026-09-21, src/ai/judge-pair.ts).** The
  first judge is asked as before. Only if it fires is a second model asked the same frozen
  question at the same cut, and the action happens only if both fire. The second call therefore
  lands on about a tenth of items. There is deliberately no middle action for the items only one
  judge flags: weighted to the population base rate that bucket is right 43 percent of the time,
  and they take the same no-action path as anything else the judges pass. Pre-registered in
  docs/research/provider-2026-09-21/PREREGISTRATION-TEST-READ.md with the bar committed before
  the sealed split was opened: both firing was right 126 of 126 on the held-out 500 and 115 of
  115 on dev, honest precision floor above 93 percent against 78.4 for the single judge, recall
  50.4 against 63.6. The record's judge block says `judge-v1-pair` and names both models whenever
  two models read the item, and `judge-v1` with one model where only the first ran.
- The adult judge is the measured instrument: the prompt text, model, schema, message shape, cut and hide line in src/ai/prompts.ts are what docs/research/accuracy-2026-09-03/PROTOCOL.md measured. The current figures are from 2026-09-21, after inference moved provider and the whole protocol was re-run on both: precision 78.4 percent [69.1, 85.5], recall 63.6 percent [57.5, 69.3] against JUDGE-V1 at severity 4 on 500 held-out items, with a second 500 at 83.2 and 62.0. The 2026-09-03 run of the same protocol on the same items read 100 and 58.8, which is the size of the drift a served model carries on its own and the reason a figure here is dated. Both runs and the provider comparison are in docs/research/provider-2026-09-21/RESULTS.md. No triage in front of it, no per-technique severity floor or confidence re-cut after it (overallConfidence is a fixed 0.9, above every mode threshold). The rewrite path is injected through options.rewrite (pipeline.ts passes neutralizeText), so neutralizer.ts adds no ai-layer import. A change to any of those is a new instrument and needs a new measurement. The on-demand reading (`readWithJudgeV1`, since 2026-09-05) asks through the same `askJudgeV1` and applies no cut, because it acts on nothing. Lock: tests/unit/ai/judge-v1-adult.test.ts, which covers the read entry too.
- The proxy allows openai/gpt-oss-20b and openai/gpt-oss-120b by name from the client and pins anything else to the 20b (worker/src/proxy.ts CHAT_MODELS_ALLOWED); metering charges each model at its own price (usage-weights.ts, both copies). Lock: tests/unit/worker-proxy-caps.test.ts, tests/unit/usage-weights-parity.test.ts.
- VISION §1.1 chain-completeness: every observed post produces a chain record regardless of action — even cancelled (cancelMidFlight carries AnalysisResult) and triage-pass (buildBenignTriageResult returns analysis). Enforced in pipeline.ts:process (post-cascade abort check) and neutralizer.ts:combinedDetectAndNeutralize.
- VISION §1.2 protection-bar: when in doubt PASS. Codified as the cardinal rule in the pipeline.ts header. Operationalized: any exception in process() returns passWith('pre-llm-ai-call-failed') from the outer catch.
- Cap and coordinator visibility (2026-08-10): callAI maps the proxy's 503 usage_coordinator_unavailable to the non-retried 'coordinator-unavailable' AIFailure kind (retry allowlist unchanged: rate-limit/transient-http/network only) with a console error naming the fault.
- Master AI breaker: settings.aiAnalysisEnabled === false makes callAI return Err(cap-exhausted, cap='master-off') before the license read and before any network call. Single chokepoint guarantee for all AI spend. Locked by tests/unit/storage/client-master-breaker.test.ts.
- failClosed symmetry on free tier: callAI returns Err(cap-exhausted, tier-free) BEFORE any network call; pipeline.ts:process also returns passWith('pre-llm-free-tier-no-ai') when `tierCap === 0` after the cost-zero filters. Both paths preserve the slur/profanity/harm-floor detections that fire before the gate.
- Proxy concurrency cap: MAX_CONCURRENT_PROXY_FETCHES=5, enforced by the module-private withProxyFetchSlot around callAI's fetch only. probeProxy and the TSA client fetch the proxy outside it; the content-script ProcessingQueue admits five jobs to match.
- Proxy-cap latch: a 429 whose body says `cap_daily` or `cap_monthly` sets an in-memory latch plus the `textCapReached` storage marker (TEXT_CAP_STORAGE_KEY, `{cap, periodKey, licenseFingerprint}`), hydrated once per realm and checked before every call; while the UTC period matches and the fingerprint matches the current licence (a latch left by a different key does not bind; markers without a fingerprint are honoured) callAI returns Err(cap-exhausted) without a network call. The popup Home tab and the Issues panel read the marker. Dev tier never latches. Lock: tests/unit/ai/text-cap-latch.test.ts
- JSON-mode retry-once: on json-refusal error, callAI retries exactly once without response_format (client.ts:callAI). Permanent errors (auth, content-policy, aborted, cap-exhausted) are NOT retried.
- Determinism: temperature=0, seed=42 on every request (client.ts:callProxyOnce).
- Rewrite validator before cache write: neutralizer.ts:combinedDetectAndNeutralize calls validateNeutralization() (8 checks) before neutralized is set; neutralize-only.ts:neutralizeText calls validateRewrite() before cacheRewrite(). Rejected rewrites are never cached. Both post and comment paths share visible-output language safety via visible-output-safety.ts.
- Per-technique × per-mode severity floor is code-authoritative over prompt: severityFloorFor() over SEVERITY_FLOOR_BY_TECHNIQUE_AND_MODE (neutralizer.ts). Prompt can emit any severity; pipeline enforces the floor.
- No provider key in the extension: the proxy holds the master key; extension sends only fw-{tier}-{secret} bearer (client.ts:callAI).
- Language-guard: only ro/en detections invoke validateRewriteLanguage; other languages pass through silently (pipeline.ts:process, language guard).
- Judge confidence: a missing or out-of-range `confidence` becomes 0.5 and a missing `severity` becomes 5 (neutralizer.ts:judgeToCombinedShape); the per-mode threshold (0.45 child / 0.55 teen / 0.60 adult) then decides, so a model shape drift passes child and fails teen / adult.
- Borderline severity reduction: when `overallConfidence < threshold + 0.10` every present technique's severity drops by one (floor 1) before the action is chosen (pipeline.ts:process).
- Ad-hominem rejection: visible-output-safety.ts rejects profanity, slurs AND ad-hominem tokens in any rewrite before display, in every mode.

## How it SHOULD work

0. The parent blocklist (`src/core/parent-blocklist.ts`) runs first, ABOVE the dedup cache, in every mode and on every tier; a hit returns `hide` with detectionMode `blocklist:<kind>:<rule>`. 1. PostContent enters process(). 2. Pre-LLM cost-zero filters (slur → hide, coded harm → hide, sponsored → collapse in all modes (Adult gets a category-only collapse), profanity child → hide, soften when `blanketProfanitySoften` and `softenAiAllowed`, dehumanization → hide, violence-narrating-video (child/teen) → hide) fire sequentially with no LLM call. 3. L1 regex detect() runs. 4. Harm-floor fires if score ≥ threshold and no L1 hit. 5. Free-tier and cap checks gate the LLM call. 6. combinedDetectAndNeutralize runs the two-stage triage: TRIAGE_STAGE1 call first (yes/unsure/no); 'no' short-circuits to benign; others fall through to the full JUDGE_DETECT_NEUTRALIZE call. 7. JUDGE prompt returns 8-field JSON (concerning, acts_on_reader, primary_concern, severity, confidence, uncertainty_reason, should_rewrite, neutralized_text). 8. judgeToCombinedShape translates to legacy CombinedResponse. 9. acts_on_reader gate: concerning=true but acts_on_reader=false AND severity≤7 → downgrade to benign. 10. Severity floor, technique mapping (`mapConcernToTechnique` is the only bridge from the judge's free-text concern to the technique enum; `combined` is the fallback, so a persisted `combined` means UNCATEGORISED, never "several techniques at once", and `judgeToCombinedShape` emits a one-element `techniques` array so it can never carry components; lock: tests/unit/ai/combined-technique-meaning.test.ts), rewrite validation (8 checks). 11. pipeline.ts applies the confidence threshold, the borderline severity reduction, the high-risk pass-through, the language guard and `hideOnRewriteUnavailable`. 12. PipelineResult returned with appropriate action.

## How it ACTUALLY works

SHA-256 cache lookup (`processingCache.getPersistent`, key built by storage/cache-key.ts). 2. Slur filter (`filterProfanity` tier 'slurs'): runs for ALL modes including adult; a hit HIDEs immediately. 2b. Coded-harm floor (`detectCodedHarm`, hide-tier categories) → HIDE through the shared `codedHarmVerdictFields` mapping; all modes, all tiers. 3. Sponsored gate: `post.is_sponsored` → action='collapse' in every mode; child / teen assert the 'consumer-rapid-frame' record as before, adult returns a category-only analysis (`isManipulative:false`, empty techniques, detectionMode 'sponsored-ad:adult') so the export counts it as an ad, not a flag (the earlier adult carve-out was reversed; the code comment records it). 4. Profanity (`filterProfanity` tier 'profanity'): child → HIDE. Then the too-short / non-substantive reject (MIN_TEXT_LENGTH 12, fewer than 3 words) sits here, after the deterministic hides. Soften: when `blanketProfanitySoften(settings, platform)` (the `soften-swearing` toggle or `strictLanguage`; not a mode wire) AND `softenAiAllowed` (`tierCap > 0`, breaker not holding, daily and monthly caps) the text goes to `neutralizeText()`; a non-empty rewrite is re-checked by `detectDehumanization`, `detectViolenceNarratingVideo` (video kind) and `detectHarmLaundering(original, rewritten)`, any trip → HIDE; a closed gate falls through to the next steps. 5. Dehumanization (`detectDehumanization`) → HIDE. 6. Violence-narrating-video (`detectViolenceNarratingVideo`): `kind === 'video'` and child or teen only. 7. L1 `detect()` over the 20 classifiers, then the author profile is asked from the service worker (GET_AUTHOR_PROFILE) for one use: `getExposurePressure(profile, creativeHash(post.text))` into `exposure`, evaluated against the profile as it stood BEFORE this sighting (result-apply records the sighting afterwards). Until 2.5.1 the same profile also raised every present L1 confidence by 0.15 for a "repeat offender" (`getSuspicionBoost`, deleted); no stored count moves a verdict now (lock: `tests/unit/storage/pipeline-harm-gates.test.ts`, "the author profile feeds the exposure notice only"). 8. Harm-floor (`computeHarmFloor`): fires only when `techniques.length === 0`. 9. Free-tier gate: `tierCap === 0` → passWith('pre-llm-free-tier-no-ai'). 10. Daily + monthly token budget → passWith('pre-llm-cap-*'). 11. `isHolding()` → passWith('pre-llm-ai-call-failed', failureKind 'pre-llm-circuit-breaker'). 12. Perf tracer span (no-op unless `captureV2Metrics`) around `combinedDetectAndNeutralize(..., {twoStageCascade:true, rewriteEnabled, platform, kind:'post', rewrite: neutralizeText})`. 12a. Adult mode (unless `legacyJudge`): `judgeV1Adult()` builds the measured user message (platform, kind, parent text for a comment, the item), calls `callAI` with `model: JUDGE_V1_MODEL`, `jsonSchema: JUDGE_V1_SCHEMA`, `maxTokens: 600`; `parseJudgeV1` rejects anything but the five-field shape (null, so the pipeline records a failed call); fire = charged and severity >= 4, else a benign analysis; on a fire the family maps to a technique, severity >= 8 gives action 'hide' with no rewrite, below it `options.rewrite` runs and its output passes stripEmojis, the 5-char floor and validateNeutralization; with no rewrite, severity >= 7 hostile or threat gives 'hide', otherwise action undefined (marker only). Returns without touching steps 13 to 21. 13. Child and Teen: `triageStage1()` runs; 'no' returns buildBenignTriageResult; yes / unsure / parse_fail fall through. 14. L1 flags assembled into the user prompt; with flags uses the flags template, without the no-flag template; the system prompt is `buildJudgeDetectNeutralizeSystem(mode)` or, with the `reframe-rewrites` toggle off, `buildJudgeDetectOnlySystem(mode)`. 15. `callAI()` with jsonMode:true, no maxTokens override (4096 default). 16. `extractCombinedJSON()`: direct JSON.parse → regex-extract {} block → single-quote fix. 17. `judgeToCombinedShape()`: acts_on_reader gate (severity > 7 bypasses it); `mapConcernToTechnique` tests the direct-harm categories first (self-harm, sexual, violence-graphic, drug-promotion, unsafe-health-experiment) so a judge verdict naming one keeps its own name and floor instead of collapsing to 'combined' (lock: tests/unit/ai/neutralizer-acts-on-reader-gate.test.ts); missing or out-of-range confidence → 0.5, missing severity → 5. 18. Technique verification loop: maps L1 names → AI verdicts; adds AI-discovered extras if in VALID_TECHNIQUES; severity floors applied. 19. `validateNeutralization()`: min-length(5), detectMetaTalk, detectFalseSelfAdmissionPath, detectInjectedAdvisory, detectLengthRatioBlowupTier, detectRegisterFlattening, FORBIDDEN_META_PATTERNS, and detectUnsafeVisibleLanguage() for profanity / slurs / ad-hominem tokens in the final visible output (8 checks). 20. If valid: stripBundleScaffolding → stripEmojis → sha256(original) → NeutralizedContent. 21. HIDE-fallback D-5: isManipulative and neutralized===null and no aiOriginalAction AND sev>=7 AND hostile technique (shame-attack, scapegoating, anger-trigger, fear-appeal) → action='hide'. 22. ## Data flow (through this subsystem)

1. PostContent (from content/index.ts queue) -> process() -> pre-flight signal check ONLY. The "too-short (<MIN_TEXT_LENGTH=12 chars) / non-substantive (<3 words)" LLM-noise reject is DEFERRED to after the cost-zero deterministic HIDE gates below (relocated 2026-08-01): placing it up front let a post whose entire text is a slur / "kill yourself" / (child) profanity pass with zero protection. It now runs just before the soften/LLM path (after the child-mode profanity HIDE gate, step 4), guarding only the work it needs to (short-fragment LLM false positives).
1b. settings + active blocklist -> matchParentBlocklist(post) (core/parent-blocklist.ts) -> HIDE with `blocklist:<kind>:<rule>`, every mode and tier, ABOVE the cache lookup
1c. textHash -> processingCache.getPersistent -> cached result short-circuits (cache-key.ts builds the key from platform / mode / locale / outputLanguage / text)
2. post.text -> filterProfanity(tier='slurs') -> slurResult; if filtered -> HIDE
2b. post.text -> detectCodedHarm() -> hide-tier category (directed self-harm/predation/doxxing/narrated-violence) -> HIDE via shared codedHarmVerdictFields (same mapping as the comment path)
3. post.is_sponsored -> ad gate (pipeline.ts) -> action='collapse' immediately in ALL modes. Child / teen carry the 'consumer-rapid-frame' severity-6 analysis; Adult carries a category-only analysis (`isManipulative:false`, no techniques, detectionMode 'sponsored-ad:adult') so the ad is collapsed and recorded as an ad, never as a manipulation flag. (A 2026-08-02 adult skip was reversed; the code comment records why.)
4. post.text -> filterProfanity(tier='profanity'); child mode -> HIDE; then the too-short reject; then, when blanketProfanitySoften(settings, platform) (toggle or strictLanguage) AND softenAiAllowed (paid tier, breaker, daily and monthly caps) -> neutralizeText() (neutralize-only.ts) -> rewrite re-checked by the dehumanization / violence / laundering gates -> accept, HIDE, or fallthrough
5. post.text -> detectDehumanization() -> if triggered -> HIDE
6. post.text -> detectViolenceNarratingVideo(); video kind, child or teen -> if triggered -> HIDE
7. post.text -> detect() (detector.ts) -> TechniqueResult[] L1; author profile via GET_AUTHOR_PROFILE -> getSuspicionBoost
8. post.text + TechniqueResult[] -> computeHarmFloor(); if triggers and L1 empty -> action='collapse' synthesized
9. `tierCap === 0` OR cap exhausted OR isHolding() -> passWith(pre-llm-*)
10. post.text + TechniqueResult[] + mode/locale/author/context + signal -> combinedDetectAndNeutralize() (neutralizer.ts), inside a perf-trace span when captureV2Metrics is on
11. combinedDetectAndNeutralize: fencePostText(text) -> TRIAGE_STAGE1_USER_TEMPLATE -> callAI(TRIAGE_STAGE1_SYSTEM, userPrompt, jsonMode=false) (neutralizer.ts:triageStage1) -> raw string
12. raw -> parseTriageVerdict() (prompts.ts) -> 'no'|'yes'|'unsure'|'parse_fail'
13. 'no' -> buildBenignTriageResult() (neutralizer.ts) -> {analysis, neutralized:null} returned
14. 'yes'/'unsure'/'parse_fail' -> build the judge user prompt (neutralizer.ts) with fenced text + author + context block + L1 flags
15. JUDGE user prompt -> callAI(buildJudgeDetectNeutralizeSystem(mode) or buildJudgeDetectOnlySystem(mode), userPrompt, jsonMode=true, maxTokens=4096) (neutralizer.ts)
16. callAI -> master breaker, tier, client daily cap, cap latch -> withProxyFetchSlot -> fetchWithDeadline POST https://api.feelingwise.org/v1/chat/completions with Bearer fw-{tier}-{secret}
17. HTTP response -> error classification (client.ts) -> rate-limit / transient-http / network retry once with backoff; json-refusal retry once without jsonMode; a 429 cap body sets the cap latch; other errors -> Err(kind)
18. 2xx body -> trackTokenUsage() + recordGroqCallTelemetry() + Ok(text)
19. raw LLM string -> unwrapOrEmpty() -> extractCombinedJSON() (neutralizer.ts): JSON.parse → regex-extract → single-quote fix
20. JudgeOutput -> judgeToCombinedShape() (neutralizer.ts): acts_on_reader gate, mapConcernToTechnique, confidence default 0.5 / severity default 5 -> CombinedResponse with techniques[], action, neutralizedText

## Design rule: detect always, rewrite on purpose (ratified 2026-08-11)

The question was what gate the per-post spend (TRIAGE_STAGE1 + JUDGE_DETECT_NEUTRALIZE) should honor, given that the old per-platform reframe gate was removed BECAUSE skipping the pipeline silenced the forensic chain (VISION section 1.1 chain-completeness, the invariant above). Design, checked against the VISION doc:

1. **Detection is never feature-gated.** Both promises hang on it: the chain must record what the feed served (Promise 1), and the harm floors must see every post (Promise 2). The only total-off levers stay the master breaker (`aiAnalysisEnabled`) and the free tier. No per-platform or per-feature switch may skip the triage/judge detection path; this section is the standing law the removed gate violated.
2. **The rewrite is a spend tier, and today it has NO owning switch.** Traced 2026-08-11: `applyNeutralizedRewriteTerminal` (content/index.ts) injects the calmer version unconditionally on a `neutralize` action; `show-reframe-markers` gates only the dot. That is the literal form of the owner's founding complaint (with reframe off, calls were still made): the switch he sees governs the light, not the load. Fix: a `reframe-rewrites` feature toggle (preset ON in child, teen, and adult so defaults are unchanged; per-platform override supported) owns BOTH the on-screen calmer version and the rewrite spend tier.
3. **With the toggle off, the judge call goes lean.** `combinedDetectAndNeutralize` requests DETECTION ONLY (prompt variant without the rewrite block): same detection quality, same chain record, the rewrite's output tokens (the majority of the response) saved. Action policy folds to the existing rewrite-unavailable floor (`mark`, or `collapse` under hideOnRewriteUnavailable), which is already honest on screen and in the record. Chain records from the lean call carry `detectionMode: 'combined-detect-only'` so an exported record never implies a rewrite was attempted.
4. **Purpose check, not mode wire.** The gate reads the feature toggle (and per-platform override) only; mode influences it solely through presets, per mode-rails law. Harm floors, slur/profanity hides, and hide/collapse severities are visibility rails and move not at all.
5. **Not in scope:** gating TRIAGE_STAGE1 separately (it is already the cheap stage and its verdict feeds chain completeness), and any change to the comment-batch path (its per-purpose OR-gate was verified correct).

IMPLEMENTED 2026-08-11: `reframe-rewrites` FeatureId (settings.ts, ON in all three presets), popup row "Calmer rewrites (AI)" / "Rescrieri mai calme (AI)" (license-aware, under Rewrite swearing), `buildJudgeDetectOnlySystem` in prompts.ts (derives from the full judge prompt by replacing the rewrite-section marker; falls back loud to the full prompt if the marker drifts), `rewriteEnabled` option on `combinedDetectAndNeutralize`, pipeline purpose check stamping `combined-detect-neutralize` vs `combined-detect-only` at every combined return site. Locks: tests/unit/storage/reframe-rewrites-toggle.test.ts. Provenance follow-up RESOLVED 2026-08-11: post-llm PASS results now carry the judge-variant stamp from the pipeline (`detectionMode` on the pass PipelineResult) and the post-llm PASS_LOG emitter forwards it. The empty-caption video PASS emitter still stamps the full-call literal with aiSource 'rules'; that shape predates the toggle, no LLM runs on that path, and it is untouched deliberately (changing a locked record shape needs its own pass).
