Pool a panel's exports

Choose every export your volunteers sent, or drop them here together. Each file is checked first; a file that fails its check is left out and named. The rest become one dataset in which every record keeps its signature, and two tables: one for a spreadsheet, one for 4CAT's "Custom/other" upload.

Nothing leaves your computer. This page loads only the two scripts beside it and makes no network request; you can open it with the network off.

The SHA-256 of each file is the one its volunteer was shown after the export and asked to send with it. If the two differ, the file you hold is not the file they made.

"Already in the pool" counts records a person exported twice: they are kept once. A text one person was shown twice counts as two sightings by one recorder, and only a text shown to different recorders counts as seen by several. Two files signed by keys of the same install are one recorder.

A pool says each record's content is what its key signed. It does not say who held a key, that a panel is complete, or that anything a record says is true. The format is written down in FORMAT.md beside this file, section 10.
